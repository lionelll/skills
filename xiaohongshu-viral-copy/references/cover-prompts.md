# Cover Text And Image Prompts

## Cover Text

Generate 1-3 cover options with:

- Main title: 6-14 Chinese characters, biggest visual element.
- Subtitle: one clear benefit, contrast, or audience cue.
- Sticker/corner label: `实测`, `清单`, `避坑`, `新手友好`, `收藏版`.

Keep the cover simpler than the post title. Use one focal message.

## Cover Prompt Template

Use this when the user asks for an image-generation prompt:

```text
生成一张小红书竖版封面，比例 9:16。整体风格：[风格]。
画面主体：[主体/场景]。
提示词结构：主体 + 描述 + 场景 + 风格 + 细节 + 构图。
排版要求：主标题最大，至少是正文的 2 倍；副标题次级；文字之间有明显留白；只对关键词使用醒目色。
视觉层次：加入少量贴纸、图标或手写标注，但不要干扰阅读。
文案：
主标题：[主标题]
副标题：[副标题]
角标：[角标]
```

## General Image Prompt Framework

When the user wants a note illustration instead of only cover text, build prompts with:

- Subject: product, person, scene, screenshot-style layout, checklist board, food, place, device, or document.
- Description: concrete traits, action, texture, mood, visible details.
- Scene: room, shop, desk, street, mirror, kitchen, commute, classroom, office, outdoor route.
- Style: clean lifestyle photo, editorial product photo, bright tutorial cover, warm diary, high-end minimalist, energetic youth, professional review.
- Details: light, materials, props, text blocks, sticker elements, depth of field.
- Composition: vertical 9:16, centered subject, close-up, flat lay, before/after split, grid layout, mobile-safe margins.

Keep the visual prompt aligned with the copy's promise and category.

## Cover Quality Rules

- Do not put too much text on the cover.
- Use contrast: big title, small support text, one highlight color.
- Keep important text away from edges.
- Prefer visible content or product cues over generic decorative background.
- Avoid asking for brand logos, celebrity faces, or copyrighted characters unless the user owns or provides them.
