# Tag Strategy

Use 8-15 tags for a full note unless the user asks for fewer. Mix precise search terms with broader discovery tags.

## Tag Mix

- Core category: what the note is about, such as `#护肤`, `#AI工具`, `#上海探店`, `#职场成长`.
- Specific object: product, method, location, ingredient, template, route, dish, tool, role, or style.
- Audience: `#学生党`, `#打工人`, `#新手`, `#宝妈`, `#敏感肌`, `#留学生`.
- Scene: `#通勤`, `#早八`, `#周末去哪儿`, `#居家办公`, `#旅行攻略`, `#约会`.
- Benefit or pain point: `#提效`, `#避坑`, `#省钱`, `#补水保湿`, `#简历优化`, `#低成本`.
- Content format: `#测评`, `#教程`, `#清单`, `#保姆级攻略`, `#真实体验`, `#合集`.

## Combination Patterns

Product review:

```text
#产品测评 #真实测评 #[品类] #[核心卖点] #[适合人群] #[价格带] #避坑 #好物分享
```

Tutorial:

```text
#教程 #新手必看 #保姆级攻略 #[主题] #[场景] #[目标人群] #收藏备用
```

Local visit:

```text
#[城市]探店 #[商圈/地标] #[品类] #周末去哪儿 #人均[价格] #真实体验 #避坑
```

AI/software:

```text
#AI工具 #效率工具 #[具体工具名] #[使用场景] #打工人必备 #教程 #提效
```

Career/productivity:

```text
#职场成长 #效率提升 #[岗位/人群] #[具体方法] #打工人 #模板分享 #经验复盘
```

## Quality Rules

- Do not use irrelevant trending tags.
- Include the most searchable noun, not only mood words.
- Prefer `#真实测评`, `#避坑`, `#教程`, `#清单` only when the content actually matches.
- For regulated categories, avoid tags that imply guaranteed outcomes.
