# Roadshow And Video Adaptation

Use this when a deck must become a narrated roadshow, product demo video, or presentation video.

## Added Deliverables

- Per-slide narration script.
- Per-slide timing.
- Transition notes.
- Subtitle text.
- Voice style.
- Music or sound direction, if requested.

## Timing

- Simple cover or section page: 5-10 seconds.
- Normal content slide: 30-60 seconds.
- Data slide: 45-90 seconds.
- Demo or roadmap slide: 60-120 seconds.

## Script Structure

For each slide:

```text
Slide [n] - [title]
Duration: [seconds]
Narration:
...
Transition:
...
Subtitle summary:
...
```

## Video Deck Rules

- Use fewer words on slides than a live presentation deck.
- Make visuals carry more of the explanation.
- Add explicit transitions between sections.
- Use subtitle-friendly sentences.
- Avoid slide elements that require the viewer to pause and inspect tiny text.

## Final Checks

- Narration matches slide content.
- Timing is realistic.
- No slide requires unexplained context.
- Subtitles are concise.
- Visual style remains consistent from first to last slide.
