# Visual System

## Style Selection

Choose based on audience and topic:

- Executive business: restrained palette, clear hierarchy, dense but organized layouts.
- Investor pitch: confident contrast, strong section dividers, product and traction visuals.
- Product launch: product-first visuals, feature cards, demo flow, crisp screenshots.
- Training: readable layouts, examples, callouts, simple diagrams.
- Academic: neutral style, clear figures, restrained decoration.
- Roadshow/video: larger typography, fewer words, more visual moments.

## Layout Types

- Cover.
- Agenda.
- Section divider.
- Title and content.
- Two-column comparison.
- Three-card framework.
- Data/chart page.
- Timeline/roadmap.
- Process flow.
- Matrix/2x2.
- Quote/testimonial.
- Closing/action page.

## Visual Prompt Formula

When generating image or cover prompts, use:

```text
Subject + description + scene + style + details + composition
```

For slide visuals, specify:

- 16:9 aspect ratio.
- Safe margins for text.
- Where text should not be placed.
- Brand colors or mood.
- Whether the result should be a photo, diagram, editorial illustration, or product render.

## Chart Guidance

- Trend over time: line chart.
- Category comparison: bar chart.
- Part-to-whole: stacked bar or pie only when categories are few.
- Funnel: funnel chart or staged flow.
- Contribution: waterfall chart.
- Relationship: scatter plot.
- Process: flow diagram.
- Strategy choice: matrix.

Do not use charts as decoration. Every chart needs one clear takeaway in the title.

## Consistency Rules

- Keep title placement consistent.
- Use one dominant type scale.
- Use one accent color for emphasis.
- Use repeated layout rhythms across similar slides.
- Avoid mixing unrelated illustration styles.
- Ensure screenshots and images have consistent framing.
